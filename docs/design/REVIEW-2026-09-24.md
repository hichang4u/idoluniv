### 1.2 주석 hex 와 실제 OKLCH 값 불일치 (중간)

`globals.css` 주석의 hex 와 OKLCH 값이 서로 맞지 않는다. 계산으로 확인했다.

| 토큰 | 주석 | OKLCH → sRGB 계산값 |
|---|---|---|
| `--background` L88 | `#0f0f1a` | `#020409` (거의 검정) |
| `--card` L90 | `#1a1a2e` | `#090c16` |
| `--primary` L59/94 | `#a855f7` | `#9752ff`. Tailwind purple-500 은 hue 303.9 인데 토큰은 293.6 |
| `--accent` L65/100 | `#ec4899` | `#fd2e80`. Tailwind pink-500 은 hue 354.3 인데 토큰은 3.8 |

목업은 OKLCH 값을 그대로 옮겼으므로 목업과 구현은 서로 일치한다. 다만 **둘 다 주석이 가리키는 의도(더 밝은 남색 배경, Tailwind purple/pink)와 다를 수 있다.** 어느 쪽이 의도인지 확인이 필요하다. 배경이 `#020409` 이면 카드와 배경의 구분도 약해진다(아래 1.4).

## 3. 판단 요청: PostCard 제목 `line-clamp-1` 대 `line-clamp-2`

**의견: 목업 기준으로는 `line-clamp-2` 가 맞다. 기존 2줄로 되돌리기를 권한다.**

근거:
1. **목업의 출처.** annotation 은 "PostCard 의 수치는 실제 컴포넌트에서 옮겼음"이라고 적었다. 목업 제목 스타일 14px / 600 / line-height 1.375 는 HEAD 의 `text-sm font-semibold leading-snug line-clamp-2`(`git diff HEAD -- components/board/PostCard.tsx`) 와 정확히 같다. 목업 `<h3>` 에 clamp 가 없는 것은 샘플 제목이 모두 한 줄에 들어가기 때문이고, 1줄 제한을 의도했다는 증거는 없다.
2. **1줄 제한은 의도된 변경이 아니다.** `line-clamp-1` 은 PostCard 가 정한 값이 아니라 shadcn `ItemTitle` 기본값(`item.tsx:133`)을 그대로 물려받은 것이다. `board/page.tsx`·`chat/page.tsx` 의 그룹명처럼 짧은 라벨에는 1줄이 맞지만, 게시글 제목에는 맞지 않는다.
3. **한국어 제목 길이.** 390px 뷰포트에서 제목 폭은 약 324~332px 이고, 14px 한글은 한 줄에 약 23자가 들어간다(추정: 한글 1자 ≈ 1em). 목업 샘플 "컴백 티저 2차 해석 — 콘셉트 연결고리 정리"(24자)부터 이미 1줄을 넘는다. 팬 커뮤니티 제목은 "[정보]", "(고화질 원본)" 같은 접두·접미가 붙어 길어지기 쉽다. 1줄이면 핵심어가 잘릴 가능성이 크다.
4. **다른 화면과의 구분.** 목업에서 1줄 ellipsis 는 프로필 "내가 쓴 글"(13px/500, 보조 목록)에만 쓰였다. 주 피드 카드와 보조 목록을 다르게 처리한 것으로 읽힌다.

구현 메모 (frontend-dev):
- 전역 `ui/item.tsx` 는 바꾸지 말고 `PostCard.tsx` 에서 `<ItemTitle className="line-clamp-2 font-semibold break-keep">` 처럼 덮어쓴다.
- `ItemTitle` 기본 클래스에는 `line-clamp-1` 과 `flex` 가 함께 있다. `line-clamp` 가 필요로 하는 `display: -webkit-box` 와 `flex` 가 충돌하므로, 현재 1줄 제한이 실제로 걸리는지도 불확실하다 [렌더 확인 필요]. `cn`(tailwind-merge 호환)은 뒤에 오는 `line-clamp-2` 가 앞의 display 클래스(`flex`)를 제거하는 것으로 알고 있다(라이브러리 설명 기준, 미검증). 적용 후 렌더링에서 2줄 말줄임이 되는지 반드시 확인한다.

> 공통 규칙: 새 색은 만들지 않는다. `.dark` 토큰만 쓴다. 모바일(<768px, `useIsMobile` 기준)에서 모든 터치 대상은 최소 44px 로 한다. `components/ui/*` 는 variant 를 추가할 때만 수정하고 기존 variant 기본값은 바꾸지 않는다.

### P0 — 이동·핵심 조작 불가, 잘못된 상태 표시

**S1. 모바일 하단 탭바 + 셸 정리**
- 새 컴포넌트 `components/layout/BottomTabBar.tsx`(client). `md:hidden fixed inset-x-0 bottom-0 z-40`, 높이 `h-16` + `pb-[env(safe-area-inset-bottom)]`, `bg-card border-t border-border`, `grid grid-cols-5`.
- 항목: 홈 `/` (Home), 게시판 `/board` (ClipboardList), 그룹 `/groups` (Mic), 채팅 `/chat` (Zap), 마이 `/profile` (User). 아이콘 22px(`size-[22px]`), 라벨 `text-[10px] font-medium`, 간격 4px.
- 상태: 활성 `text-primary` + `aria-current="page"`. 활성 판정은 `Sidebar.tsx:35-36` 과 같은 규칙을 공유하도록 `navItems` 를 공용 모듈로 뺀다. 비활성은 `text-muted-foreground`. 각 칸 전체가 링크(높이 64px).
- 숨김: `/chat/[groupSlug]` 에서는 렌더하지 않는다(annotation "채팅 화면의 탭바 제거").
- `layout.tsx`: 모바일에서 본문 하단에 `pb-16`(탭바 높이). `Footer` 는 `hidden md:block`. `Header` 의 `SidebarTrigger`·구분선은 `hidden md:flex`.
- 데스크톱(md 이상): 기존 Sidebar 를 유지한다.
- `/groups`, `/profile` 라우트가 생기기 전까지 탭은 둘 중 하나로 처리한다. (a) 탭을 `aria-disabled` 로 두고 "준비 중" `sonner` 토스트를 띄우거나, (b) 최소 placeholder 페이지를 만든다. 404 로 보내지 않는다.

**S2. 채팅 입력 영역 44px + 높이 계산**
- `ChatRoom.tsx:166-196`: 닉네임 `Input className="h-11 w-24"`, 메시지 `Input className="h-11 flex-1"`. 전송은 InputGroup 안 `xs` 버튼 대신 **별도 `Button`** `className="h-11 w-12"`(default variant, `Send` 아이콘 18px, `aria-label="전송"`). 전송 중에는 `Spinner`, 비활성은 `disabled`(내용 없음 또는 전송 중).
- 다른 곳에서도 44px 가 반복되므로 `button.tsx` 에 `size: { touch: "h-11 px-4 gap-1.5", "icon-touch": "size-11" }` 추가를 권장한다.
- placeholder 는 "메시지를 입력하세요…"(Enter 안내는 `md:` 이상에서만 보이도록 하거나 삭제).
- `chat/[groupSlug]/page.tsx:55` 의 `calc(100vh - 9rem)` 을 제거한다. 채팅방은 헤더를 뺀 나머지를 `h-[calc(100dvh-3.5rem)]`(모바일, 전역 헤더 56px 기준)로 채우고, 푸터·탭바는 숨긴다. `loading.tsx` 도 같은 높이와 입력 높이(h-11)로 맞춘다.

**S3. PostForm 유형 선택 상태 수정**
- `PostForm.tsx:52`: input 에 `peer` 클래스를 추가하고 `className="peer sr-only"` 로 한다. 칩에 `peer-focus-visible:ring-3 peer-focus-visible:ring-ring/50`. 칩 높이 `h-11 px-4 text-sm`(목업 Board 필터 칩과 같은 형태: 비활성 `border-border text-muted-foreground`, 활성 `border-primary/40 bg-primary/10 text-primary`, `rounded-full`).
- 구조를 바꾼다면 `components/ui/tabs.tsx` 대신 radio 그룹을 유지한다(폼 제출 호환).

**S4. 댓글·상세 액션 터치 영역과 권한 표시**
- `CommentItem.tsx:50-66`: 답글·삭제를 `Button variant="ghost" size="touch"`(또는 `h-11 px-3 text-xs`)로 바꾼다.
- 삭제·수정은 `author_id === 현재 사용자 id` 일 때만 렌더한다(상세 `[postId]/page.tsx:112-120`, 댓글 `CommentItem.tsx:59`). 서버 검사는 이미 있으므로 UI 표시만 맞춘다.
- `[postId]/page.tsx:113`: `<Link><Button>` 중첩 대신 `Button nativeButton={false} render={<Link …/>}` 패턴(`board/[groupSlug]/page.tsx:86-90` 과 같은 방식)을 쓴다.

### P1 — 목업 불일치 중 UX 영향이 큰 것

**S5. PostCard 를 목업 수치로 복원 (`Item` 유지)**
- `PostCard.tsx`: `<Item variant="outline" className="rounded-xl bg-card p-4 gap-0 hover:border-primary/40">`.
- 배지: `<Badge variant="outline" className="h-auto border-primary/30 bg-primary/10 text-primary text-[0.65rem]">`. 대비 4.26 이라 AA 미달이므로 `text-xs`(12px)로 올리는 것을 권장한다. 크기를 키워도 여전히 4.5 미만이라, 이 조합은 "굵은 라벨 예외"로 받아들일지 결정이 필요하다.
- 제목: `<ItemTitle className="mt-1.5 line-clamp-2 w-full font-semibold break-keep">`(§3).
- 본문: `<ItemDescription className="mt-1 text-xs leading-[1.45]">`(line-clamp-2 유지).
- 하단: `mt-3`, 아이콘 `size-3`, 조회·좋아요·댓글 + 북마크(스크랩 여부를 표시할 수 있으면 `fill-current text-primary`, 없으면 목업처럼 아이콘만).
- 메타 줄: 닉네임 `min-w-0 truncate`.
- `[groupSlug]/loading.tsx` 스켈레톤을 같은 모양으로 맞추고 `components/ui/skeleton.tsx` 를 사용한다.

**S6. 그룹 게시판 헤더 · 정렬 칩**
- 하위 화면 헤더 패턴(게시판·채팅·상세 공통): 모바일에서 전역 헤더 대신 `[뒤로 size-11 ghost icon] [제목 text-base font-bold truncate] [우측 액션 size-11]`. 새 컴포넌트 `components/layout/PageHeader.tsx`(title, backHref, actions). 데스크톱은 기존 유지.
- 그룹 헤더 블록: `Avatar` 48px `rounded-lg` + 그라데이션 폴백(`bg-gradient-to-br from-primary/20 to-accent/20 text-primary font-bold`), 이름 `text-sm font-semibold`, 보조 `text-xs text-muted-foreground`("게시글 {count}"; 팬 수는 데이터가 생긴 뒤), 우측 글쓰기 `Button size="touch"` + `Plus` 아이콘.
- 정렬 칩: 최신순 / 인기순(`like_count desc`) / 팬픽(`post_type = fanfic`). `?sort=` 쿼리로 서버에서 처리한다. 칩 `h-11 rounded-full px-4 text-[13px]`, 활성·비활성은 S3 칩과 같다. `role="tablist"` 또는 링크 그룹에 `aria-current`.
- 빈 상태: 필터 결과가 0이면 "팬픽이 아직 없어요" 등 필터별 문구를 쓰고, CTA 는 `size="touch"`.

**S7. 채팅 메시지 스타일 — 목업의 평면 스타일로**
- `MessageItem.tsx`: `Bubble variant="ghost"`(bg·패딩 제거, `bubble.tsx:33`)를 쓴다. `MessageAvatar className="self-start mt-0.5"`, `Avatar className="size-7"` + `AvatarFallback className="bg-gradient-to-br from-primary/20 to-accent/20 text-primary text-xs font-semibold"`.
- 헤더: 닉네임 `text-foreground font-medium`, 시간 `text-muted-foreground font-normal ml-2`. ghost 일 때 `px-0` 은 `message.tsx:63` 이 자동 처리한다.
- 본문: `text-sm leading-relaxed`(1.625).
- 내 메시지(목업 미정 → 제안): 같은 `session_id`/`author_id` 이면 닉네임 옆에 `Badge` "나"를 붙이거나 닉네임을 `text-primary` 로 표시한다. 좌우 정렬 분리는 목업에 없으므로 하지 않는다.
- 목록 컨테이너: 메시지가 적을 때 아래에 붙도록 `flex flex-col justify-end`(단 스크롤 컨테이너와 분리: 바깥 `overflow-y-auto`, 안쪽 `min-h-full flex flex-col justify-end`).
- 채팅방 헤더: S6 `PageHeader`(title "{group.name} 채팅방"). 우측 접속 필은 presence 구현 전까지 생략한다.
- 연결 상태: `channel.subscribe((status) => …)` 로 `CHANNEL_ERROR`/`TIMED_OUT`/`CLOSED` 일 때 목록 위에 `text-xs text-destructive` 배너 "연결이 끊겼어요. 다시 연결 중…"을 띄운다. 복구되면 숨긴다.

**S8. 대비 · 오버레이 · 하드코딩 색**
- `PostActions.tsx:69-70`: `red-*` 를 `accent` 로 바꾼다(`border-accent/40 bg-accent/10 text-accent`, hover 동일 계열). accent/card 대비는 5.47 로 통과한다.
- `sheet.tsx:31` 오버레이 `bg-black/60`.
- `primary-foreground/primary` 4.06: 토큰 조정이 필요하다(디자인 결정). 안은 둘이다. (a) `--primary` L 을 0.58 안팎으로 낮춰 흰 글자 대비 4.5 이상 확보(단 primary 텍스트/card 대비가 떨어지므로 재계산 필요), (b) 버튼 글자를 `font-semibold` + 16px 이상으로 올려 큰 텍스트 기준(3:1)으로 운영. **결정 전까지 frontend-dev 는 토큰을 건드리지 않는다.**
- `muted-foreground` 를 `bg-muted` 위에 쓰는 칩(`chat/page.tsx:37` 등)은 `text-secondary-foreground`(대비 13.45)로 바꾼다.

**S9. 한국어 줄바꿈 · 오버플로**
- 제목·헤딩·빈 상태 문구에 `break-keep`.
- 상세 본문 `[postId]/page.tsx:100`, 댓글 `CommentItem.tsx:45` 에 `wrap-break-word`(overflow-wrap). 효과 없는 `prose prose-sm prose-invert` 는 제거한다.
- 상세 메타 줄 `[postId]/page.tsx:81` 에 `flex-wrap gap-y-1`.
- `--font-sans` 에 한글 폴백을 추가한다: `var(--font-geist-sans), "Pretendard", "Apple SD Gothic Neo", "Malgun Gothic", system-ui, sans-serif`(목업 font-family 와 같다). Pretendard 웹폰트 로딩 여부는 별도 결정.
- 텍스트 입력은 모바일에서 16px(`text-base md:text-sm`)로 한다. `PostForm.tsx:81,97`, `CommentForm.tsx:46` 의 raw input/textarea 를 `components/ui/input.tsx`·`textarea.tsx` 로 교체하면 해결된다.

**S10. 에러 · not-found 상태**
- `app/(main)/error.tsx`(client): `Empty` + `EmptyTitle` "문제가 생겼어요" + `EmptyDescription` + "다시 시도" `Button size="touch"`(`reset()`).
- `app/(main)/not-found.tsx`: `Empty` + "페이지를 찾을 수 없어요" + 홈으로 버튼.
- 목록 쿼리(`board/page.tsx:23`, `[groupSlug]/page.tsx:57`, `chat/page.tsx:25`)에서 `error` 가 있으면 throw 해서 `error.tsx` 로 보낸다. 빈 상태와 구분하기 위해서다.
- 로딩이 없는 라우트(`/board`, `/chat`, 작성·수정)에 `loading.tsx` 를 추가하고 `Skeleton` 을 쓴다.

### P2 — 신규 화면(데이터 선행 필요)

**S11. 팬 프로필 `/profile`** (§2.6 요소 순서대로)
- 비로그인: `Empty` + "로그인하고 내 활동을 확인하세요" + 로그인 `Button size="touch"`. 로그아웃 버튼은 헤더에서 이 화면의 설정(톱니 `size-11`) 메뉴(`dropdown-menu` 또는 `drawer`)로 옮긴다.
- 프로필 카드 `Card`: `Avatar` 72px(`size-18`), 레벨 배지 `Badge` primary 필, 진행 바 `components/ui/progress.tsx`(트랙 `bg-muted`, 인디케이터 `bg-gradient-to-r from-primary to-accent`, 높이 8px).
- 통계 3칸: `grid-cols-3 gap-2`, 각 칸 `rounded-lg border bg-card p-3 text-center`.
- 배지 그리드 4열: 획득은 아이콘 `text-primary`/`text-accent`, 미획득은 `border-dashed text-muted-foreground`. 라벨은 목업 10px 대신 `text-[11px] break-keep`.
- 내가 쓴 글: `Item size="sm"`, 제목 `truncate`(1줄, 목업대로), 메타 `text-[11px] text-muted-foreground`. 빈 상태 "아직 쓴 글이 없어요" + 게시판 이동.
- **백엔드 선행**: 레벨별 exp 임계값, 배지 메타 정의, 통계 집계.
